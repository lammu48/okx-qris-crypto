## Kesalahan Umum Pemula Beli Kripto Pakai QRIS di OKX

Beberapa kesalahan yang sering bikin pemula bingung atau bahkan rugi:

Ini kesalahan paling fatal. Begitu kamu klik tombol ini, merchant akan nunggu dana masuk. Kalau nggak masuk dalam waktu tertentu, merchant bisa ajukan sengketa. Kalau ini terjadi berulang, akun kamu bisa kena pembatasan. Selalu pastikan transfer udah bener-bener dilakukan sebelum klik.

Tiap order punya timer. Kalau timer habis dan kamu belum tandai "sudah bayar", order otomatis batal dan kripto dikembalikan ke merchant. Kalau kamu sering bikin order kadaluarsa, akun kamu bisa kena pembatasan P2P. Selalu cek timer sebelum konfirmasi order.

**Keluar dari aplikasi saat transaksi belum selesai**

Sambil nunggu merchant konfirmasi, tetap buka aplikasi. Kalau ada chat dari merchant atau notifikasi penting, kamu bisa langsung respon.
